Convex hull lookahead insertion:
1. Do convex hull
2. For each unvisited points
3. Do shortest insertion and save the visited node index
4. Add point to a virtual visited node list
5. For i = 1 until i == depth
6. For each node in virtual visited do shortest insertion
7. For the shorest add node in order for virtual visited list and accumulate total length
8. Repeat step 5
9. For the lowest total route addition, add node in step 2 at index saved in step 3 to the real visited list
10. repeat step 2 until all nodes are in visited list

Convex hull inverse insertion:
1. DO convex hull
2. For each unreached point find the sqaure distance from each reached point, plus the shortest distance
3. Do insertion sort for the point with the lowest distance
4. repeat step 2-4 until every point in reached
